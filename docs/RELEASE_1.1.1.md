# DEFYN 1.1.1

Corrige sincronização de rotina entre dispositivos e migração segura de rotinas locais criadas em versões anteriores.

O upgrade local para IndexedDB v9 preserva dias e horários, converte IDs antigos em UUIDs estáveis e mantém operações pendentes prontas para sincronizar. O formato de backup permanece v7 e o schema Supabase não muda.
